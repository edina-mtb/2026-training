# 🟢 June Training Plan — High School MTB (Pre-Season Base + Build)

## Month Snapshot

- **Dates:** June 1–30, 2026
- **Phase:** Pre-Season Base
- **Secondary Overlay:** Build
- **Primary Focus:** keep aerobic volume high while introducing selective race exposure

---

## 🎯 Primary Objectives

- Continue building aerobic base and durability
- Add race opportunities selectively, not automatically
- Use short-course events for intensity and skills
- Use endurance events for long aerobic work
- Protect recovery between hard efforts

---

## 📅 Standard Weekly Rhythm

- **1 interval day** or race-simulation effort
- **1 easy ride + skills day**
- **1 endurance ride (key weekend session)**
- **1–2 strength sessions**
- **Optional extra easy riding** only if recovery remains stable

### Beginner / Intermediate / Advanced Adjustments

- **Beginner:** 3–4 rides/week, race selectively, shorter endurance event choices
- **Intermediate:** 4–5 rides/week, standard race substitution rules
- **Advanced:** 5–6 rides/week, longest endurance sessions, optional additional easy volume if fresh

## 🚴 Key Workouts

### 1. Interval / Race-Simulation Day
Purpose:
- support the move from pure base toward selective intensity

Example:
- 5–6 x 3 min moderate-hard efforts
- or 3–4 race-pace hill efforts with full recovery

### 2. Easy Ride + Skills Day
Focus:
- cornering under mild fatigue
- braking
- body position
- trail flow

### 3. Endurance Ride

- **Beginner:** 75–105 min
- **Intermediate:** 2–2.5 hours
- **Advanced:** 2.5–4 hours
- **Intensity:** mostly conversational

### 4. Strength Training

- core
- mobility
- hip / glute strength
- light upper-body support

---

## 🔁 Weekend Substitution Rules

- **Missed XC simulation race:** replace with interval day only if it was intended to be the week’s hard race-simulation effort
- **Missed endurance event:** replace with endurance ride
- **No weekend event selected:** default to endurance ride
- **Two event options in one week:** choose one focus, not both

---

## 🧠 Coaching Guidelines

- Keep most volume easy
- Add races selectively, not automatically
- Protect the long ride / endurance stimulus
- Avoid turning every available event into a maximal effort
- Build fitness without losing consistency

---

## ✅ Weekly Checklist

- 1 interval / short-course race / XC simulation effort
- 1 skills ride
- 1 endurance ride or endurance event
- 1–2 strength sessions
- no stacked hard efforts
